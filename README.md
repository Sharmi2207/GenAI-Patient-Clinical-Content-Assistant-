## 📌 Project Overview

The **Patient & Clinical Content Assistant** is an intelligent, retrieval-augmented medical question-answering assistant designed to deliver accurate, citation-backed health information without hallucination risks.

### Key Highlights:
- **Zero-Hallucination Retrieval**: Grounded directly on the **MedQuAD** dataset comprising **16,406 verified medical Q&A pairs** from 9 official National Institutes of Health (NIH) institutes (including MedlinePlus, CDC, Cancer.gov, NIDDK, and NINDS).
- **Direct Citations**: Every answer is delivered with transparent confidence scores, topic tags, and official NIH source URLs for full clinical provenance.
- **Safety Guardrails**: Automatically detects acute emergency queries (e.g., severe chest pain, breathing difficulty, stroke symptoms) and safely redirects users to emergency healthcare services (999/911/111).
- **Interactive Web Interface**: A modern, responsive conversational UI that allows users to ask health queries and explore dataset analytics in real time.
